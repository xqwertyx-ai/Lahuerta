# La Huerta del Pianista

Un cuaderno de campo para cuidar una finca familiar en Ojuelos Bajos (Fuente Obejuna, Córdoba): dehesa, encinas, granito, un gato y una melodía incompleta. Nadie recuerda quién fue el pianista que le dio nombre.

- **Jugar**: abre `dist/index.html` en el navegador (funciona sin servidor y sin conexión), o publica la carpeta `dist/` en GitHub Pages para instalarlo como app.
- **Desarrollar**: `npm start` y abre http://localhost:8080. Sin dependencias ni compilación.
- **Contenido**: todo está en `src/data/`. Ver [docs/AUTOR.md](docs/AUTOR.md).
- **Estado**: [PROJECT_STATUS.md](PROJECT_STATUS.md).

Controles: toca una zona del plano para cuidarla; arrastra para moverte y pellizca (o rueda) para acercarte. Teclado: espacio = pausa, 1/2/3 = velocidad, C = cuaderno, Esc = cerrar.

Tipografías Caveat y Patrick Hand (Google Fonts, licencia OFL, en `fonts/`). Todo el arte y la música se generan con código en el navegador.
